# PIXEL SURVIVAL · 최후의 불씨

> 아기 용과 수호수들이 마지막 불씨를 지켜요.
> 흩어진 불씨 조각을 모아 꺼져 가는 세상을 다시 밝히세요.

브라우저에서 바로 즐기는 픽셀 서바이벌 로그라이크예요. 몰려오는 적을 자동 공격으로 물리치며 버티고, 레벨업마다 캐릭터 고유 스킬을 골라 강해져요.

🎮 **플레이하기:** https://jiho0913jiho-oss.github.io/pixel-survival/

---

## 세계관
아주 오래전, 재의 숲 한가운데에는 꺼지지 않는 불씨의 둥지가 있었어요. 어느 밤 **식음의 그림자**가 서리 바람을 몰고 와 불씨를 산산이 흩어 놓았고, 둥지 곁에서 잠들어 있던 아기 용 **이그니**만이 꼬리 끝에 작은 불꽃을 지닌 채 깨어났어요.

흩어진 **불씨 조각**(경험치)을 모아 그림자를 물리치고 둥지로 돌아가는 것이 이그니의 이야기예요. 사방을 지키는 **사신**(주작·현무·백호·청룡)과 중앙의 **황룡**, 빛의 영수 **기린**도 저마다의 땅에 불씨를 되돌려 놓기 위해 함께 싸워요.

## 플레이 방법
| 조작 | PC | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면을 누른 채 드래그 |
| 공격 | 자동 | 자동 |
| 일시정지 | P | 화면 위 일시정지 버튼 |
| 전체 화면 | F | 앱으로 설치하면 자동 |
| 웨이브 스킵 / 타이틀로 | N / T (설정에서 변경 가능) | — |

- 적을 처치하면 떨어지는 **불씨 조각**을 모아 레벨업해요.
- 레벨업할 때마다 나오는 강화 3개 중 하나를 골라요. 대부분 **캐릭터 고유 스킬**이에요.
- 보물상자, 제단, 자석 같은 아이템도 맵 곳곳에 있어요.

## 게임 모드
- **스토리:** NIGHT 1부터 50까지 버티면 클리어예요. 10 NIGHT마다 보스가 나오고, NIGHT 50의 **식음의 그림자**가 마지막 보스예요. 이지와 하드 난이도가 있어요.
- **마법의 탑:** 층을 하나씩 올라가는 모드예요. 5층마다 **탑의 수문장**, 100층에는 **흑룡왕 아스트라**가 기다려요. 이지는 목숨 3개, 하드는 1개예요.

## 캐릭터
| 캐릭터 | 종류 | 속성 | 얻는 방법 |
|---|---|---|---|
| 🐉 이그니 | 아기 용 | 🔥 잿불 (그을림) | 처음부터 |
| 🐦 주작 | 불의 신수 | 🔥 업화 (화상) | 코인 20 |
| 🐢 현무 | 물의 신수 | 💧 물 (둔화) | 코인 15 |
| 🐯 백호 | 바람의 신수 | 🌪 바람 (베임) | 코인 20 |
| 🐲 청룡 | 번개의 신수 | ⚡ 번개 (감전) | 코인 25 |
| 👑 황룡 | 중앙의 신수 · 사신의 왕 | ⛰ 땅 (석화) | 사신 4마리를 모두 Lv40까지 진화시키면 해금 |
| 🦄 기린 | 빛의 영수 · 사령의 으뜸 | ✨ 빛 (낙인) | 코인 40 |

- 캐릭터마다 공격 방식, 고유 스킬, 무기 진화, 엔딩이 모두 달라요.
- **Lv20과 Lv40에 진화**해서 모습과 능력이 바뀌어요.
- 황룡은 진화하려면 시련 보스(**Lv20 도철**, **Lv40 혼돈**)를 쓰러뜨려야 해요.

## 맵
캐릭터마다 전용 맵이 있고, 맵마다 그곳에만 사는 **맵 전용 몹**이 나와요.

| 맵 | 주인 | 맵 전용 몹 |
|---|---|---|
| 재의 숲 | 이그니 | 🍄 등불 버섯: 쓰러지면 두 마리로 갈라져요 |
| 불타버린 땅 | 주작 | 🦎 잿불 도롱뇽: 달아오른 뒤 돌진해요 |
| 얼어붙은 북해 | 현무 | 🐧 썰매 펭귄: 셋이 함께 미끄러지며 돌진해요 |
| 은빛 억새 협곡 | 백호 | 🌪 모래 회오리: 지그재그로 다가와 밀어내요 |
| 봄비 벚꽃 계곡 | 청룡 | 🌸 꽃잎 요정: 주변 적을 회복시켜요 |
| 오방천궁 | 황룡 | 🦁 돌사자 석상: 돌일 땐 단단하고, 가까이 가면 덮쳐요 |
| 구름 성소 | 기린 | ☁ 구름 정령: 안개로 흩어지면 공격이 안 통해요 |

## 성장과 수집
- **클리어 코인:** 스토리 클리어, 마법의 탑 10층마다, 일일·주간 퀘스트로 얻어요.
- **강화 상점:** 코인으로 체력, 공격, 경험치, 이동 속도 등을 영구 강화해요. 단계가 오를수록 비싸져요.
- **일일 · 주간 퀘스트:** 일일 퀘스트는 매일 0시, 주간 퀘스트는 매주 월요일 0시에 바뀌어요. 몹 처치, 보스, 탑 등반 같은 목표를 깨면 코인을 받아요.
- **기록 · 업적 · 도전과제 · 칭호:** 업적을 달성하면 칭호를 얻고 장착할 수 있어요.
- **도감:** 캐릭터, 적, 보스, 맵, 엔딩이 기록돼요.
- **캐릭터별 엔딩:** 어떤 캐릭터로 클리어하느냐에 따라 엔딩이 달라요. 7개 엔딩을 모두 모으면 전설 칭호를 얻어요.

## 저장
- 진행 상황은 브라우저에 자동으로 저장돼요.
- **☁ 클라우드 저장:** 구글 계정으로 로그인하면 PC와 휴대폰 등 여러 기기에서 이어서 할 수 있어요. (Firebase 사용)
- **세이브 백업:** 설정에서 저장 코드나 파일로 내보내고 불러올 수 있어요.

## 앱으로 설치
- **안드로이드:** 크롬으로 접속 → 설정 → **앱으로 설치** (또는 크롬 메뉴 ⋮ → 앱 설치)
- **아이폰:** Safari로 접속 → 공유 버튼 → **홈 화면에 추가**
- **PC:** 크롬이나 엣지 주소창 오른쪽의 설치 아이콘

설치하면 주소창 없이 전체 화면으로 실행되고, **인터넷이 없어도** 플레이할 수 있어요.
※ 카카오톡 같은 앱 안의 브라우저에서는 설치가 안 돼요. 크롬이나 Safari로 열어 주세요.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조와 메뉴 |
| `styles.css` | 화면 스타일 |
| `game.js` | 게임 전체 (게임 루프, 캐릭터, 적, 보스, 맵, 사운드, 메뉴, 저장) |
| `sw.js` | 오프라인 실행을 위한 서비스 워커 |
| `manifest.webmanifest` | 앱 설치 정보 (이름, 아이콘, 가로 화면) |
| `icon-*.png`, `apple-touch-icon.png` | 앱 아이콘 |
| `bgm_title.mp3`, `bgm_tower.mp3`, `bgm_field.mp3` | 배경음악 (없으면 8비트 음악이 대신 나와요) |

## 직접 실행하기
`index.html`을 바로 열어도 플레이할 수 있어요. 다만 배경음악 mp3와 오프라인 실행은 웹 서버에서만 작동해요.

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
